CORS 與部署疑難排解提示：

  • 誰可以存取 (Who has access)：Apps Script 部署設定務必設為 任何人 (Anyone)。
  • 執行身分 (Execute as)：需設為 我 (Me)，確保腳本能以您的權限寫入試算表。
  • 修改代碼後：必須點擊「部署」>「管理部署」> 編輯並將版本升級至「新版本」，否則修改不會生效。
